# راه‌اندازی همکاری در فروش راه‌یاب کالا از طریق افیلیو

وضعیت فعلی: ناشر و رسانهٔ راه‌یاب هنوز در افیلیو ثبت/تأیید نشده‌اند. فایل `data/affiliate/affiliate-links.json` عمداً خالی است؛ بنابراین لینک‌های فعلی مستقیم‌اند و پورسانتی برای راه‌یاب ایجاد نمی‌کنند.

## مسیر رسمی راه‌اندازی

1. راه‌یاب باید ابتدا روی یک دامنهٔ عمومی و قابل بازدید منتشر شود. `localhost` و مخزن GitHub به‌تنهایی رسانهٔ عملیاتی نیستند.
2. ثبت‌نام ناشر در پنل رسمی: https://publisher.affilio.ir/
3. در پنل، رسانهٔ وب‌سایتی با دامنهٔ راه‌یاب تعریف و احراز هویت/تأیید ناشر و رسانه تکمیل شود. صفحهٔ رسمی ناشران افیلیو سه گام ثبت‌نام، تعریف رسانه و احراز هویت را اعلام می‌کند. کانال رسمی سیستم کسب درآمد دیجی‌کالا نیز امکان فعالیت «رسانه‌های فروشگاهی» قدیمی و جدید را با ثبت رسانهٔ فروشگاهی و انتشار لینک افیلیت اعلام کرده است؛ بنابراین راه‌یاب مسیر درخواست دارد، اما پذیرش نهایی آن به بررسی و تطبیق با ضوابط رسانه‌های فروشگاهی وابسته است.
4. پس از تأیید رسانه، فروشگاه دیجی‌کالا از فهرست فروشندگان انتخاب و برای هر محصول، لینک اختصاصی رهگیری (deep link) ساخته شود.
5. لینک‌های صادرشدهٔ پنل در `data/affiliate/affiliate-links.json` با شناسهٔ دقیق محصول ثبت شوند. الگوی هر رکورد:
   ```json
   {
     "publisher_status": "approved",
     "media_status": "approved",
     "media_url": "https://YOUR-DOMAIN/",
     "tracked_links": {
       "12345678": {
         "url": "https://ACTUAL-TRACKING-URL-FROM-AFFILIO",
         "store": "digikala"
       }
     }
   }
   ```
   URL نمونه واقعی نیست. پارامتر رهگیری را نباید حدس زد یا از URL عمومی محصول ساخت.
6. سایت فقط وقتی ناشر و رسانه هر دو `approved` باشند و لینک HTTPS اختصاصی آن محصول موجود باشد، لینک افیلیو را به‌کار می‌برد. در غیر این صورت لینک مستقیم باقی می‌ماند.
7. تمام نقاط خروجی محصول باید از resolver مشترک استفاده کنند: کارت جست‌وجو، گالری عکس، پنل اطلاعات گراف و دکمه‌های خرید. لینک‌های رهگیری با `rel="sponsored nofollow"` مشخص می‌شوند.

## سازوکار انتساب پورسانت

کاربر باید از یک لینک رهگیری اختصاصی عبور کند تا کلیک و سپس سفارش در سامانه افیلیو به رسانه نسبت داده شود. صرف بازدید از راه‌یاب یا جست‌وجوی نام کالا در دیجی‌کالا کافی نیست. اگر کاربر از لینک مستقیم، جست‌وجوی گوگل یا مسیر دیگری وارد دیجی‌کالا شود، راه‌یاب نمی‌تواند انتساب پورسانت را تضمین کند. همچنین سفارش پرداخت‌نشده، لغوشده یا مرجوعی الزاماً سفارش موفق قابل‌تسویه نیست.

در اطلاعیهٔ رسمی سیستم کسب درآمد دیجی‌کالا، «ثبت خرید» برای سفارش پرداخت‌نشده یا سفارش لغوشده پیش از پرداخت به‌کار رفته است. همان کانال اعلام کرده استفاده از کد تخفیف ممکن است کمیسیون را کاهش دهد یا صفر کند.

## مواردی که باید در پنل/از پشتیبانی افیلیو تأیید شوند

- آیا راه‌یاب باید به‌عنوان «رسانهٔ فروشگاهی» ثبت شود یا «رسانهٔ محتوایی/راهنمای خرید»؟ چون راه‌یاب سفارش‌گیر و فروشنده نیست و کاربر را به فروشگاه مقصد می‌فرستد، طبقه‌بندی دقیق آن را پیش از ثبت نهایی از افیلیو بگیریم.
- آیا پنل فعلی API، خروجی گروهی لینک‌ها، Smart Widget یا feed مجاز محصول دارد؟
- بازهٔ انتساب کوکی، مدل attribution (مانند آخرین کلیک)، خرید بین‌دستگاهی و قواعد جایگزینی انتساب چیست؟
- کمیسیون روز هر دسته، کالاهای مستثنا، سقف، اثر کد تخفیف، لغو و مرجوعی چیست؟
- نمایش قیمت، تصویر، عنوان، مشخصات و موجودی از طریق API/Widget افیلیو مجاز است؟ محدودیت cache و به‌روزرسانی چیست؟
- حداقل پرداخت، دورهٔ تسویه و مدارک مالیاتی موردنیاز چیست؟

تا زمانی که این شرایط و تأیید رسانه روشن نشده‌اند، نباید به بازدیدکننده وعده داد «هر خریدی از دیجی‌کالا برای راه‌یاب پورسانت دارد». فقط سفارش منتسب به لینک رهگیری مجاز و تأییدشده، طبق قواعد افیلیو، می‌تواند کمیسیون ایجاد کند.
