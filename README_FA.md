# راه‌یاب کالا — نمونهٔ آزمایش اتصال زنده

این نسخه به‌جای داده‌های ثابت، از سرور محلی Node.js درخواست می‌فرستد و چند مسیر جست‌وجوی آزمایشی دیجی‌کالا را امتحان می‌کند. برای واژه‌های کلی مانند «موتور»، چند عبارت گسترش‌یافته نیز بررسی می‌شوند تا مشخص شود جست‌وجوی چندمسیره چه چیزی به نتیجهٔ اصلی اضافه می‌کند.

## رفع خطای تفسیر `run.ps1` در Windows PowerShell 5.1

اگر پیام `The string is missing the terminator` دیدی و متن فارسی در خطا به‌هم‌ریخته بود، نسخهٔ قبلی فایل با encoding ناسازگار خوانده شده است. فایل `run.ps1` در این بسته با نویسه‌های ASCII بازنویسی شده تا این خطا رخ ندهد. فایل قدیمی را با نسخهٔ این بسته جایگزین کن.

## اجرا در Windows

1. ZIP را استخراج کن.
2. مطمئن شو Node.js نصب است (نسخهٔ 18 یا جدیدتر).
3. پوشهٔ استخراج‌شده را باز کن.
4. در نوار آدرس File Explorer بنویس `powershell` و Enter بزن.
5. این دستور را اجرا کن:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

صفحه در Chrome یا مرورگر پیش‌فرض باز می‌شود. اگر پورت 4173 از قبل استفاده شده باشد، اجرای برنامه با آن پورت ممکن است تداخل کند.

## چه چیزی را آزمایش می‌کند؟

- تلاش برای جست‌وجو با `https://api.digikala.com/v3/search/` و سپس مسیر `v1/search/`؛
- گسترش محدود جست‌وجوی واژه‌های کلی مانند موتور، پمپ، باتری و ابزار؛
- استخراج عنوان، شناسه، تصویر، قیمت و لینک محصول از پاسخ‌های JSON با ساختارهای رایج؛
- مقایسهٔ جست‌وجوی داخلی با لینک جست‌وجوی گوگل برای صفحات دیجی‌کالا؛
- نمایش شفاف خطا اگر API قابل‌دسترسی نباشد یا ساختار پاسخ آن تغییر کرده باشد.

## محدودیت‌ها و ملاحظات

- مسیرهای API استفاده‌شده در این نمونه مستندات عمومی رسمی برای ناشران افیلیت نیستند؛ از پروژه‌های متن‌باز عمومی برای شناسایی آن‌ها استفاده شده است.
- این فایل مجوز استفادهٔ تجاری، ذخیره‌سازی تصاویر/قیمت‌ها یا استخراج انبوه داده را ایجاد نمی‌کند. برای محصول واقعی، قبل از بهره‌برداری باید از دیجی‌کالا/افیلیو مجوز و فید یا API پایدار بگیریم.
- یک نتیجهٔ API لزوماً به معنی موجودبودن فعلی کالا نیست. قیمت و موجودی باید روی دیجی‌کالا بررسی شود.
- این نسخه هنوز در محیط سازنده نتوانسته به API زنده وصل شود، چون دسترسی DNS شبکهٔ این محیط برقرار نبود. پس موفقیت اتصال باید روی سیستم خودت آزمایش شود.
- اگر API تغییر کرده یا پاسخ مسدود شود، دکمه‌های گوگل و جست‌وجوی مستقیم دیجی‌کالا برای بررسی دستی باقی می‌مانند.

## توقف سرور

پنجرهٔ Node را در Task Manager ببند یا در PowerShell اجرا کن:

```powershell
Get-NetTCPConnection -LocalPort 4173 -State Listen -ErrorAction SilentlyContinue | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```

## فایل‌های اصلی

- `server.js` — سرور محلی و اتصال به مسیرهای آزمایشی
- `public/index.html` — رابط کاربری فارسی
- `run.ps1` — راه‌اندازی از Windows PowerShell


## اصلاح بارگذاری تصاویر (نسخهٔ آزمایشی بعدی)

- استخراج نشانی تصویر از چند ساختار متداول JSON، از جمله `images.main.url[0]` و `seo.open_graph.image`.
- بارگذاری تصویر از مسیر محلی `/api/image` به‌جای درخواست مستقیم مرورگر به میزبان تصویر؛ این کار مشکلات ارجاع‌دهنده/بارگذاری مستقیم مرورگر را دور می‌زند، اما اگر رایانه به میزبان تصویر دسترسی شبکه نداشته باشد، تصویر همچنان بارگذاری نمی‌شود.
- پروکسی فقط میزبان‌های تصویر `dkstatics-public*.digikala.com` و مسیر محصولات را می‌پذیرد، مقصد تغییرمسیر را دوباره بررسی می‌کند و برای هر تصویر سقف ۶ مگابایت دارد.
- رابط وضعیت «نشانی تصویر پیدا نشد» را از «تصویر قابل دریافت نیست» تفکیک می‌کند و تعداد محصولاتی را که نشانی تصویر معتبر دارند نشان می‌دهد.

این اتصال همچنان یک نمونهٔ فنی با endpointهای غیررسمی است؛ برای استفادهٔ تجاری باید مجوز و روش رسمی دریافت داده تأیید شود.
